# Demo LangGraph Agent

## 목적
수동 테스트 데모는 본 LangGraph 파이프라인과 별개로, 얇은 LangGraph agent 하나로 입력 분석, 템플릿 선택, 생성 도구 실행, 후처리, 결과 분리를 확인한다.

## 흐름
1. `agent_select`: `DemoGenerationInput`을 읽고 `select_template()`으로 주제별 학습 템플릿을 고른다.
2. `agent_generate`: `mock` 또는 실제 생성 커넥터 경로를 골라 1강 5장 결과를 만든다.
3. `agent_finish`: 슬라이드, 퀴즈, 핵심노트, 과제, 음성대본, DB 저장 preview를 분리하고 `agent_plan`을 결과에 붙인다.

## 과외 블루프린트
`tutor_blueprints.py`는 템플릿을 과외 전략으로 바꾼다. 기술 주제는 입력·상태·출력·검증, 과학 주제는 현상·원리·증거·한계, 통계 주제는 변수·분포·추론·한계, 인물 주제는 시대 문제의식·선택·업적·영향으로 설명한다. 이 값은 슬라이드 첫 설명, 핵심노트, 과제, 음성대본, 생성 프롬프트에 함께 들어간다.

## 출력 정책
- 화면은 어떤 단계에서 어떤 도구를 왜 썼는지 `agent_plan`으로 표시한다.
- 설명의 첫 블록은 목차 대신 주제가 왜 필요한지, 기본 철학, 생각 방식, 관점을 다룬다.
- 짧은 실습은 슬라이드 내부 활동이고, 퀴즈 5문항은 별도 산출물로 유지한다.
- 음성대본은 튜터 성향, 속도, 깊이, 질문우선 값을 반영해 슬라이드별 과외 멘트로 생성한다.

## Timeout 정책
- `mock`: 20초 안에 끝나 화면을 빠르게 확인한다.
- 실제 생성 커넥터: 커넥터 타임아웃을 넘기면 서버 장애와 구분해 생성 도구 지연 오류로 돌려준다.

## 프로덕션 연결성
이 agent는 본 파이프라인을 대체하지 않는다. 본 LangGraph 파이프라인의 노드 trace와 `agent_plan`을 같은 개념으로 이을 수 있게 데모 계약을 먼저 정했다.
