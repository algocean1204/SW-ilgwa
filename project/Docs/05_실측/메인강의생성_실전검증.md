# 메인강의생성 실전 검증

ChapterStudio_V1로 실전형 강의 1개를 만든 결과와 품질 점수를 적는다.

## 최종 구성 측정값

| 항목 | 초기 | 최종 |
|---|---|---|
| 1강(10~15슬라이드) 생성 시간 (준비·생성·검증·음성 포함) | 512초 | 120초 (-76.6%) |
| GPU 콜드 스타트 | 12.4초 | 0.8초 |
| 1강당 총 과금 | — | $0.38 |

커리큘럼은 Claude Opus 4.6을 1강당 1회 (커리큘럼 설계)만 호출하고, 슬라이드 내용은 Modal B200의 Qwen3.6-27B FP8을 vLLM으로 8슬롯 병렬 생성했다. 음성은 Qwen3-TTS(Modal H100)로 문장 단위 합성했다. 가중치는 GPU 스토리지에 미리 올려 두고 GPU 스냅샷으로 콜드 스타트를 줄였다.

위 표가 최종 측정 결과다. 아래 2026-05-14 기록은 최종 구성을 갖추기 전의 이전 검증이라 비용과 범위가 다르다.

## 이전 검증: 2026-05-14 Modal B200 (최종 구성 전)

이 회차들은 최종 구성 이전에 강의 생성 품질을 확인한 실행이다. TTS를 돌리지 않았고(음성 합성 제외), 비용은 그때 설정 기준의 B200 추정치다. 최종 1강당 총 과금 $0.38(음성 포함)과 직접 비교하는 값이 아니다.

산출물·품질 점수 HTML 보고서 6종(실전_산출물×3 + 품질_점수×3)은 2026-06-05 정리 때 저장소에서 뺐다. 일회성 산출물이라 팀 저장소에 두지 않았고, 원본은 아래 경로에 있다.

| 회차 | 요약 | 원본 산출물 경로 |
|---|---|---|

| 20260514_131242 | 최신 후처리 코드로 기존 payload 재생성. `flow-strip` 화살표 전용 요소 카드화 문제 수정 상태. | `Test_FastAPI_Module/ChapterStudio_V1/artifacts/modal_actual_lesson/20260514_131242/` |

`Test_FastAPI_Module/`은 저장소에 포함하지 않는다.

음성대본은 `pipeline.voice_audio.synthesize_voice_audio()`에서 TTS 커넥터로 합성하고, 결과 `audio_url`과 `duration_hint_sec`를 `voice_script` 저장 레코드에 합친다. 2026-05-14 검증에서는 강의 생성 B200 경로를 실제로 돌렸고, TTS Modal 엔드포인트는 환경변수를 설정하지 않아 음성 파일 합성까지는 돌리지 않았다. 음성대본 품질이 기준에 못 미치면 단일 대본을 반복 재호출하지 않고 `문단별 생성 -> 병합 -> 품질 gate` fallback을 쓴다.
