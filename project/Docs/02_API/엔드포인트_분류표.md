# 엔드포인트 서버 분류표

엔드포인트를 서버별로 나눈 표다. 기준은 [`Spring_API.md`](./Spring_API.md)이고, 내용이 다르면 그 문서를 따른다. 서버 역할과 여러 서버를 거치는 흐름은 [`시스템_구성과_서버_분류.md`](../01_아키텍처/시스템_구성과_서버_분류.md)에 있다.

---

## 범례

### 서버

Server 열 값은 `Spring`(Spring Boot), `FastAPI`, `Modal`(Modal GPU, FastAPI가 호출), `Composite`(여러 서버를 거치는 흐름), `Internal`(Spring↔FastAPI 내부 통신)이다. 서버별 역할과 Base URL은 [`시스템_구성과_서버_분류.md`](../01_아키텍처/시스템_구성과_서버_분류.md#서버-분류)에 있다.

### 통신 방식

| 태그 | 설명 |
|------|------|
| REST | 일반 HTTP JSON 요청/응답 |
| REST+File | multipart/form-data 파일 업로드 포함 |
| STREAM | HTTP chunked StreamingResponse 또는 상태 polling. Spring SseEmitter는 사용하지 않음 |
| Webhook | 외부 서비스가 서버로 HTTP 콜백 전송 |

### 인증

| 태그 | 설명 |
|------|------|
| Public | 인증 없음 |
| JWT | Authorization: Bearer {accessToken} (만료 30분) |
| Pro-gated | JWT + subscription_status IN ('pro','premium') 확인 필요 |
| Webhook-HMAC | `X-Telegram-Bot-Api-Secret-Token` 헤더 HMAC 검증 |
| Internal-Token | `X-Internal-Token` 헤더 공유 시크릿 검증. VPC 내부 전용 |

Free 플랜은 JWT만으로 기본 기능을 쓴다. 텔레그램, AI 튜터 커스터마이징, 무제한 슬라이드는 Pro 이상만 쓴다. 요금제별 변경 내역은 문서 끝 변경 이력에 있다.

## 쿼터 체크 미들웨어 동작 (v1.4)

> 상세 정책: [`기능명세서.md`](../00_개요/기능명세서.md) § 10 요금제, [`페이지별_기능정리.md`](../00_개요/페이지별_기능정리.md) PAGE 15

플랜별 쿼터 제한은 DB 제약 대신 API 레이어 미들웨어에서 처리한다. 구현은 Spring Boot에 있다.

### 강의 생성 쿼터 체크 (POST /tutoring)

```
요청 수신
  │
  ├─ subscription_status 조회 (user 캐시)
  ├─ 현재 강의 수 조회 (course 테이블, user_id 기준 non-deleted count)
  ├─ 플랜별 max_courses 조회 (subscription_plan 테이블)
  │
  ├─ count < max_courses  → 생성 허용
  └─ count >= max_courses → 403 QUOTA_EXCEEDED
                            { "code": "QUOTA_EXCEEDED", "plan": "free", "max": 1, "current": 1 }
```

### 슬라이드 접근 쿼터 체크 (GET /tutoring/{id}/lessons/{id}/slides)

```
요청 수신
  │
  ├─ subscription_status 조회
  ├─ max_slides_per_course 조회 (subscription_plan.max_slides_per_course)
  │
  ├─ NULL (pro/premium) → 전체 슬라이드 반환
  └─ 2 (free)        → slide_order <= 2인 슬라이드만 반환
                       초과 슬라이드는 { "locked": true, "upgrade_required": true } 형태로 포함
```

### Pro-gated 엔드포인트 공통 처리

```
요청 수신 → subscription_status IN ('pro','premium') 확인
  ├─ true  → 정상 처리
  └─ false → 403 PLAN_UPGRADE_REQUIRED
             { "code": "PLAN_UPGRADE_REQUIRED", "required_plan": "pro" }
```
